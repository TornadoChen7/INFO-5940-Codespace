# Reflection on Multi-Agent Workflow

Implementing this travel planning system helps me better understand how to write proper prompts and the responsibilities across specialized agents. Providing reviewer agents with access to Internet search tools emphasizes the importance of verification, factual accuracy, and post-processing. One agent is focusing on generating the plan based on current information, and the other one is to make sure that the plan is feasible and workable for the user. The whole workflow becomes more reliable with multi-agents than one single agent system. It provides users with a more comprehensive but also reliable results that can be followed directly. 

One of the challenges that I have faced is to make sure that the output of the planner is predictable and reliable. Reviewer should be able to interpret the contents generated by the planner consistently. Since there is a lot of data and relevant information on the internet, I have to refine the prompts given to the Planner. In the prompt, I ask the Planner to implement stable section titles, daily breakdowns, time blocks, and a clear list of assumptions. If there are not a structured output, it will be difficult for the Reviewer to read and thus fail to detect issues. Another challenge comes from integrating the "internet_search" tool. Properly setting environment variables and debugging authentication errors takes time. It also took me some time to get access to the Tavily API and get the internet searching function works.

In my ideas and prompts, the Reviewer is seemed as "Quality Assurance and Operations Manager." It helped the AI to get used to its role and define the tone of the final outputs. Its language should be concise and factual. In the meantime, the Reviewer allows the Planner to be creative and flexible in making decisions. I also consider the delta list in my prompt as a creative design choice. This format makes the version to be clear, traceable, and easy for the Reviewer to apply when generating the final corrected itinerary.
