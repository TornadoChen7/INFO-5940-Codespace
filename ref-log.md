## External Sources and Tools

| Library / Tool | Purpose |
|----------------|----------|
| **Streamlit** | Builds the interactive web interface, supports chat messages, file upload, and sidebar settings. |
| **LangChain** | Provides document abstraction (`Document`), chaining logic, and integration with vector stores and LLMs. |
| **LangChain OpenAI** | Connects to OpenAI-compatible endpoints for Chat and Embedding models. |
| **LangChain Chroma** | Manages Chroma-based vector storage and retrieval. |
| **LangChain Text Splitters** | Uses `RecursiveCharacterTextSplitter` to break documents into chunks for embedding. |
| **Chroma** | Vector database for semantic search and retrieval. |
| **PyPDF** | Extracts text from PDF files. |
| **OpenAI API (Cornell Gateway)** | Hosts chat (`gpt-4o-mini`) and embedding (`text-embedding-3-small`) models. |
| **GitHub Codespaces** | Cloud-based development environment used to run and test the Streamlit app. |

## GenAI Usage

Generative AI is primarily used for **debugging and testing** during development.  
It helps verify retrieval accuracy, inspect intermediate responses, and ensure the RAG pipeline works correctly before deployment.
